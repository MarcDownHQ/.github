# Security policy

Please report security problems privately, not in a public issue.

1. Open the **Security** tab of the affected repository.
2. Choose **Report a vulnerability** and describe the problem, how to reproduce it, and what an
   attacker could do with it.

We only maintain the latest release of each project, so please check that the problem still exists
there first. We will reply as soon as we can, and we will credit you in the fix unless you would
rather stay anonymous.
