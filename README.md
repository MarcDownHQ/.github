# MarcDownHQ/.github

GitHub reads this repository for the whole organization:

- `profile/README.md` is the public page at [github.com/MarcDownHQ](https://github.com/MarcDownHQ).
- `CONTRIBUTING.md`, `SECURITY.md` and the templates in `.github/` apply to every repository in the
  organization that has no file of its own at the same path.

This repository is public, so nothing here may name a private project or describe private
infrastructure.
